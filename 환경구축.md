
## Ubuntu Linux Machine 준비
### OrbStack에서 Linux 선택
### OrbStack에서 Terminal Login
### 배포판, 아키텍쳐 확인
```
lsb_release -a
uname -m
```
## 패키지 설치
- acl
- ufw
- openssh-server
- file
```
sudo apt update
sudo apt install -y acl ufw openssh-server file
```

## 그룹 추가
- agent-common
- agent-core
```
getent group agent-common >/dev/null || sudo groupadd agent-common
getent group agent-core >/dev/null || sudo groupadd agent-core
```

## 사용자 추가
- agent-admin
- agent-dev
- agent-test
```
id agent-admin >/dev/null 2>&1 || sudo adduser --disabled-password --gecos "" agent-admin
id agent-dev >/dev/null 2>&1 || sudo adduser --disabled-password --gecos "" agent-dev
id agent-test >/dev/null 2>&1 || sudo adduser --disabled-password --gecos "" agent-test
```

## 사용자마다 추가 그룹 등록
- agent-common (G) : agent-admin, agent-dev, agent-test
- agent-core (G) : agent-admin, agent-dev
```
sudo usermod -aG agent-common,agent-core agent-admin
sudo usermod -aG agent-common,agent-core agent-dev
sudo usermod -aG agent-common agent-test
```

## 어플리케이션 디렉토리 준비 (그룹 확인)
- /home/agent-admin/agent-app/upload_files
- /home/agent-admin/agent-app/api-keys
- /home/agent-admin/agent-app/bin
- /var/log/agent-app
```
sudo -u agent-admin mkdir -p \
  /home/agent-admin/agent-app/upload_files \
  /home/agent-admin/agent-app/api_keys \
  /home/agent-admin/agent-app/bin

sudo mkdir -p /var/log/agent-app
```

## 디렉토리 권한 수정
```
sudo chgrp agent-common /home/agent-admin/agent-app/upload_files
sudo chmod 770 /home/agent-admin/agent-app/upload_files

sudo chgrp agent-core /home/agent-admin/agent-app/api_keys
sudo chmod 770 /home/agent-admin/agent-app/api_keys

sudo chgrp agent-core /var/log/agent-app
sudo chmod 770 /var/log/agent-app
```

## Key 화일 생성
echo 'agent_api_key_test' | sudo tee /home/agent-admin/agent-app/api_keys/secret.key >/dev/null
sudo chgrp agent-core /home/agent-admin/agent-app/api_keys/secret.key
sudo chmod 640 /home/agent-admin/agent-app/api_keys/secret.key

## Firewall 준비
```
sudo ufw default deny incoming
sudo ufw default allow outgoing

sudo ufw allow 20022/tcp
sudo ufw allow 15034/tcp

sudo ufw show added
```

## SSH 설정
```
sudo mkdir -p /etc/ssh/sshd_config.d

sudo tee /etc/ssh/sshd_config.d/99-b4-1.conf >/dev/null <<'EOF'
Port 20022
PermitRootLogin no
EOF
```

## SSH 설정 확인

```
sudo sshd -t
sudo sshd -T | grep -E '^(port|permitrootlogin) '
```

## SSH 재기동
```
sudo systemctl restart ssh
sudo systemctl --no-pager --full status ssh | head -20
sudo ss -tlnp | grep sshd
```

## Firewall 기동
```
sudo ufw --force enable
sudo ufw status verbose
```

## 애플리케이션(agent-app-linux-x86) 업로드 (From Mac to Ubuntu)
- Ubuntu
```
uname -I
```

- Mac
```
scp -P 20022 agent-app-linux-x86 <Ubuntu사용자>@<Ubuntu-IP>:~
```

## 애플리케이션 확인 & 작업 디렉토리로 이동 & 소유자/권한 변경
- owner: agent-dev
- group: agent-core
- mode: 750
```
sudo file ~/agent-app-linux-x86

sudo cp ~/agent-app-linux-x86 /home/agent-admin/agent-app/upload_files/
sudo mv ~/agent-app-linux-x86 /home/agent-admin/agent-app/bin/

sudo chown agent-dev:agent-core /home/agent-admin/agent-app/bin/agent-app-linux-x86
sudo chmod 750 home/agent-admin/agent-app/bin/agent-app-linux-x86

sudo ls -l /home/agent-admin/agent-app/bin/agent-app-linux-x86
```

## 애플리케이션 실행
- 계정 전환 : agent-dev
```
sudo -u agent-dev -H bash
```

- 환경변수 설정
```
export AGENT_HOME=/home/agent-admin/agent-app
export AGENT_PORT=15034
export AGENT_UPLOAD_DIR="$AGENT_HOME/upload_files"
export AGENT_KEY_PATH="$AGENT_HOME/api_keys"
export AGENT_LOG_DIR=/var/log/agent-app

env | grep '^AGENT_'
```

- 애플리케이션 실행
```
cd "$AGENT_HOME/bin"
./agent-app-linux-x86
```

- 다른 터미널에서 검증
```
ssh -p 20022 <Ubuntu사용자>@<Ubuntu-IP>
sudo ss -tlnp | grep 15034
sudo ufw status verbose
```
